# Task 20: Sort Dataset Using Python and Pandas

## Project Overview
This project demonstrates how to sort a dataset using Python and the Pandas library as part of the Veda Technology AI & ML Internship.

## Objective
To understand and implement ascending, descending, and multiple-column sorting operations on the Iris dataset.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- CSV Dataset

## Dataset
The Iris dataset contains flower measurements, including sepal length, sepal width, petal length, petal width, and species.

## Operations Performed
1. Loaded the Iris dataset using Pandas.
2. Displayed the original dataset.
3. Sorted the dataset by sepal length in ascending order.
4. Sorted the dataset by sepal length in descending order.
5. Sorted the dataset by species and sepal length using multiple columns.
6. Exported the sorted datasets into separate CSV files.

## Output Files
- `ascending_sorted.csv`
- `descending_sorted.csv`
- `multiple_sorted.csv`

## Learning Outcomes
- Learned to use the Pandas `sort_values()` method.
- Understood ascending and descending sorting.
- Practiced sorting by multiple columns.
- Learned to export processed datasets to CSV files.

## Conclusion
This task provided practical experience in dataset sorting and data manipulation using Python and Pandas.
